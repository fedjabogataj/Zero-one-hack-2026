% ---- Problem ----
\slide{The Problem --- and why it matters}{
\begin{itemize}
  \item A wafer lot is a strict recipe: $\sim$110--150 ordered steps, $\sim$120 step types, fixed block structure, 10 hard ordering rules.
  \item Three families share a backbone but differ in prep: MOSFET ($\sim$126), IGBT ($\sim$151), IC ($\sim$107).
  \item High next-step accuracy is easy from local frequencies --- the real test is the \emph{global ordering grammar}.
  \item A held-out 4th family tests out-of-distribution (OOD) generalisation.
  \item We optimised for the \textbf{OOD-safe} choice, not the leaderboard.
\end{itemize}}

% ---- Approach 1 ----
\slide{Approach (1/3): Model \& semantic init}{
\begin{itemize}
  \item One step = one token; modelled autoregressively from \texttt{RECEIVE WAFER LOT} to \texttt{SHIP LOT}.
  \item Family identity: a learnable embedding summed into every position.
  \item LM head weight-tied to the token table (halves parameters).
  \item Token embeddings initialised from \textbf{BAAI/bge-base-en-v1.5} (768-dim): each step = name + description + parameters.
  \item Clear upgrade over our initial all-MiniLM-L6-v2 on every Task 1/2 metric.
  \item An unseen 4th-family step lands in the same semantic space.
\end{itemize}}

% ---- Approach 2 ----
\slide{Approach (2/3): Disciplined model selection}{
\begin{itemize}
  \item \textbf{L9 Taguchi orthogonal sweep}: 9 runs over LR $\{$1e\text{-}4, 3e\text{-}4, 1e\text{-}3$\}$ $\times$ depth $\{$4, 6, 8$\}$ $\times$ regularisation.
  \item Each factor level appears 3 times --- clean main effects with 1/3 the runs of a full 27-run grid.
  \item Submitted as a SLURM \texttt{-{}-array=0-8} job.
  \item \textbf{Best-val-loss checkpointing}: persist lowest-val-loss weights; the loader auto-prefers them.
  \item Critical for fairness: high-LR configs overfit earlier than low-LR ones.
\end{itemize}}

% ---- Approach 3 ----
\slide{Approach (3/3): Scored with the organizer's metric}{
\begin{itemize}
  \item Our \texttt{metrics.py} and the organizer's \texttt{eval\_metrics.py} are independent implementations of the same spec.
  \item We re-scored \emph{every} model with the organizer's scorer and picked the submission from that ranking.
  \item The two agree exactly on Top-1/3/5, MRR, edit distance, F1, ROC-AUC, rule attribution.
  \item Only Task 2 token/block accuracy drift $\sim$4--5 pts (uniform normalisation difference; rankings unchanged).
\end{itemize}}

% ---- Results 2 ----
\slide{Results (2/3): Reading the sweep}{
\begin{itemize}
  \item Across the 9 BGE runs, ROC-AUC climbs from 0.77 (low LR, 4 layers) to 0.998 (high LR, 8 layers).
  \item But Task 1/2 metrics favour \emph{low} LR.
  \item \textbf{r2} (LR 1e-4, 8 layers, dropout 0.1, wd 0.01) takes Top-1, MRR and edit distance \dots
  \item \dots while keeping ROC-AUC at a healthy 0.8773 --- our \textbf{Pareto pick}.
  \item Three runs (r4, r5, r7) had saturated anomaly scoring (ROC-AUC 0.5) and were dominated out.
\end{itemize}}

% ---- Results 3 ----
\slide{Results (3/3): Honest evidence}{
\begin{itemize}
  \item \textbf{F1 = 1.000 is essentially meaningless}: \texttt{IS\_VALID} routes through a symbolic rule checker, so every reasonable model gets perfect F1. ROC-AUC on model confidence is the honest read.
  \item We \textbf{ruled out} a naive single-config BGE run (Top-1 0.7672): the gap is too large to be anything but in-distribution overfit --- the OOD 4th family would punish it.
  \item Honest limitation: the sweep ran at \texttt{d\_model=384} (inherited from the MiniLM grid), so BGE's 768-dim embeddings were projected down --- some BGE advantage left on the table, by design, for the OOD-safe pick.
\end{itemize}}
